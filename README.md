# Acquire by Pin Africa

Site vitrine statique pour la marque et les initiatives de formation journalistique de Pin Africa : Acquire by Pin Africa.

## Présentation

Acquire by Pin Africa est une initiative de formation, de développement des médias et de renforcement des capacités pour les journalistes et créateurs de contenu africains. Ce projet consiste en une landing page moderne et immersive qui met en avant :

- la mission et les valeurs de la plateforme,
- les programmes de formation,
- l’impact sur les journalistes et les communautés,
- les partenaires institutionnels,
- les histoires d’anciens apprenants,
- les appels à l’action pour rejoindre ou découvrir les cours.

## Objectif du projet

Le site vise à présenter Acquire comme une ressource crédible et accessible pour les parcours de formation en journalisme, storytelling et reporting public-interest en Afrique. Il met l’accent sur l’expertise, la pratique, l’accès et l’impact social des programmes.

## Stack technique

Ce projet est un site statique sans framework ni build system :

- HTML5
- CSS3
- JavaScript vanilla
- Images et visuels SVG/PNG dans le dossier assets

## Démarrage rapide

### Option 1 : ouvert directement dans le navigateur

Vous pouvez simplement ouvrir le fichier `index.html` dans votre navigateur.

### Option 2 : serveur local

```bash
python3 -m http.server 8000
```

Puis ouvrez dans le navigateur :

```text
http://localhost:8000
```

## Personnalisation

Les contenus principaux sont centrés dans le fichier `index.html`.

- Le design et les styles sont dans `css/main.css`
- Les scripts de comportement se trouvent dans `js/main.js`
- Les images, logos et visuels sont dans `assets/`

## Contribution

Les modifications peuvent être faites directement dans les fichiers HTML, CSS et assets du projet. Le site étant statique, il suffit de conserver la structure existante et d’ajuster les sections selon les contenus à publier.
